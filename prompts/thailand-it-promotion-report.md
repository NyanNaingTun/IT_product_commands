# Thailand IT Promotion Report — 12:00 PM Prompt

## Schedule
Run daily at **12:00 PM Thailand time (Asia/Bangkok)**.

## Objective
Check Thailand IT deals and promotions for:
- Laptops
- Smartphones
- Tablets / iPad
- Desktop computers / PC components

Report **all currently active promotions that can be verified**, maximizing verified item coverage rather than showing only a few highlights.

## Allowed Sources
Use ONLY:
- BNN / BaNANA — bnn.in.th
- Advice — advice.co.th
- IT City — itcity.in.th
- Studio7 Thailand — studio7thailand.com
- JIB — jib.co.th
- SpeedCom — speedcom.co.th
- The product brand's **official Thailand website/store**

Do NOT use Shopee, Lazada, TikTok, Thai Nexus Man, or other non-approved sellers/sources.

## Accuracy Rules — Mandatory
1. Lock the exact product before comparing: exact model number / SKU plus relevant RAM, storage, CPU, GPU, color/variant.
2. Search the approved sources for that exact SKU.
3. Open and verify the **live exact product page**. Never use a Google/search snippet, cached result, stale indexed price, or category/search page as the final price.
4. Verify the live selling price and promotion details: sale price, coupon, member discount, card promotion, cashback, voucher, bundle, and free gifts.
5. Never assume coupons/promotions can stack. If stacking is not explicitly verified, mark **⚠️ Unverified** and do not subtract it from the final price.
6. Verify stock/status: **In Stock / Out of Stock / Coming Soon / Pre-order / Store Pickup**.
7. An out-of-stock item may be reported as the lowest listed price, but it must NOT be called the cheapest currently buyable option.
8. Compare only the exact same SKU/variant across stores. Do not compare different variants as if identical.
9. User-provided current screenshots showing the exact model and live price take precedence over stale indexed/search results.
10. If any price, stock, promo term, SKU match, or stacking rule cannot be verified, explicitly mark it uncertain instead of guessing.
11. Before declaring a **cheapest/best price**, verify the exact SKU on the live page and confirm it is currently buyable.
12. Include Thailand check date/time.

## Report Format
Keep the report highly visual, compact, and low on extra prose.

Group by:
1. 💻 Laptop
2. 📱 Smartphone
3. 📲 Tablet / iPad
4. 🖥️ Desktop / PC Components

Use a dense table such as:

| Product / Model | Spec အတို | Price Compare | 🏆 Best | Save | Stock | Buy |
|---|---|---|---|---|---|---|

For EVERY product:
- Exact product name
- Exact model number / SKU
- Very short key specs
- Promo/reference price when verified
- Save amount / percentage when available
- Stock status
- Cheapest verified source
- Direct exact-product purchase link whenever available

## Store Comparison
For each promoted product, compare the exact same SKU across the approved ecommerce stores where it is listed.

Compact example:
**BNN ฿x | Advice ฿y | JIB ฿z | SpeedCom ฿w**

Use stock markers and do not label an unavailable listing as the cheapest currently buyable offer.

## Specs
Keep specs to one short line/cell.

Laptop / PC:
**CPU · GPU · RAM/Storage · Display** when useful.

Phone / Tablet:
**Chipset · RAM · Storage · Display**.

Components:
Only the most relevant core specifications.

## Change Markers
When detectable compared with the previous report:
- 🆕 NEW promo
- 🔻 Price drop
- 🔺 Price increase
- ✅ Restock
- ❌ Out of stock
- ⏰ Promotion ending soon

## Coverage Rule
Do NOT arbitrarily stop at 3–5 products. If many active promotions are verifiable, include as many verified promotion items as possible while keeping each row compact.

## Myanmar Price Rule
Do NOT automatically convert prices to MMK in the daily Thailand report.

Only when the user explicitly asks for **Myanmar price / MMK conversion**:
1. Ask the user for the current exchange-rate variable every time.
2. Calculate:
   **Myanmar Price = ((Thai Price × 1.05) + 2,000 THB) × exchange-rate-variable × 1.15**
3. Round upward to the next MMK amount ending in **990**.
